Qué la define

  • Banner --celebrate (#FBBF24) solo en este estado — jamás en el flujo normal del cliente
  • "¡Lo lograste, Lupita!" — celebra a la persona, no al producto
  • Preview del admin con la cita de prueba visible — confianza sin necesidad de fe
  • CTA dual: compartir link + probar el formulario (test booking del Step 7)
  • El flujo de booking (Dirs A–E) y los hitos de deleite (Dir F) se combinan — no son excluyentes

¿Cómo elegir?

Podés elegir una dirección como base, combinar elementos de varias, o pedir variaciones. Lo más común: una dirección dominante para el flujo del cliente + elementos de F para los hitos emocionales de Lupita.

Si priorizás conversión de Daniela → Dirección E (Grilla Protagonista) — slots más grandes, selección más rápida en alta distracción
Si priorizás orgullo y retención de Lupita → Dirección C (Identidad Primero) + F (Celebración) — presencia de marca + hitos de deleite
Si buscás el mejor equilibrio general → Dirección B (Calidez Profesional) + elementos de F para wizard finale y primera cita
Si priorizás usuarios low-tech (Don Marco) → Dirección D (Pasos Guiados) — orientación explícita, botón atrás visible, contexto siempre presente
